# Silo Site

Marketing site for [Silo](https://github.com/Vic-Orlands/Silo), a local-first password manager built in Rust.

- [Product repository](https://github.com/Vic-Orlands/Silo)
- [Live marketing site](https://silo-ruddy.vercel.app/)

## Repository map

This repository contains Silo's marketing experience. The encrypted vault, CLI, browser bridge, desktop tray, architecture, and release documentation live in the main [`Silo`](https://github.com/Vic-Orlands/Silo) repository.

## Develop

```bash
git clone https://github.com/Vic-Orlands/silo-site
cd silo-site
pnpm install
pnpm dev
```

- `/` — primary landing
- `/v1` — alternate dark landing

## Stack

Next.js 16, React 19, Tailwind CSS 4, Motion.
